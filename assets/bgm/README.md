# assets/bgm/ — 殿の自作オリジナルBGM置き場

ここに音源ファイル(mp3 / ogg / m4a / wav)を置く。

## 手順
1. このフォルダに音源を置く。ファイル名はシーン名推奨。
   例: `town.mp3` `field.mp3` `battle.mp3` `boss.mp3` `metal.mp3` `victory.mp3` `emotion.mp3`
2. `js/audio/bgm-files.js` の `BGM_FILES` に「シーン名: "assets/bgm/ファイル名"」を登録(先頭の `/* */` を外す)。
3. `sw.js` の `ASSETS` に同じ相対パスを追加し、`C = "srq-vXXX"` を +1。

## シーンと用途
| シーン | 用途 | ループ |
|--------|------|--------|
| town | 拠点ホーム・事務所 | ループ |
| field | 冒険マップ・道中 | ループ |
| battle | 雑魚ラッシュ戦 | ループ |
| boss | 科目ボス・中ボス・ラスボス | ループ |
| metal | メタル敵出現中(焦る高速チェイス) | ループ |
| victory | 撃破・クリアの勝利ジングル | 単発(数秒・ループ不要) |
| emotion | 感動の寸劇シーン | ループ |

登録が無いシーンは内蔵の合成音で鳴る(このフォルダが空でも動く)。
